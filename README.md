# daiku

daiku plans and builds software changes in one workspace. Planning and building
each have their own optional room, and each change follows its own loop of
gated phases, from idea to shipped pull request.

daiku replaces [zumen](https://github.com/btdstudio/zumen) (planning),
[tomo](https://github.com/btdstudio/tomo) (building) and their shared core,
[kiso](https://github.com/btdstudio/kiso). It's being ported now, so only
`daiku version` works so far.
